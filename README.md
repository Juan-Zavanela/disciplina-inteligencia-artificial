# Disciplina de Inteligência Artificial

Repositório destinado ao armazenamento de atividades e cadernos desenvolvidos durante a disciplina de Inteligência Artificial.

## Conteúdo

### Exercícios de Python

Notebook contendo a resolução dos 50 exercícios de Python propostos na disciplina, abordando conceitos como:

- Variáveis e tipos de dados
- Operadores
- Estruturas condicionais
- Estruturas de repetição
- Listas
- Tuplas
- Dicionários
- Funções
- Módulos
- Tratamento de exceções

### Exercícios de Data Science (NumPy, SciPy, Pandas e Matplotlib)

Notebook contendo a resolução dos exercícios das principais bibliotecas de Data Science em Python, abordando conceitos como:

- **NumPy**: arrays, operações vetoriais e matriciais
- **SciPy**: integrais, equações diferenciais, otimização, transformada de Fourier, álgebra linear e interpolação
- **Pandas**: criação e leitura de DataFrames, filtragem, agrupamento, junção de tabelas e tratamento de dados faltantes
- **Matplotlib**: gráficos de linha, dispersão, barras, histogramas, pizza e gráficos 3D
